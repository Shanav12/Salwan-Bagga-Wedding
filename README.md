# Salwan-Bagga-Wedding

Main website for Sahil & Ambika's wedding.

## Steps to run
You must have node verion 20+. To do so, do the following:

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
source ~/.bashrc
nvm install 22.0
nvm use 22.0
```

To run the project:
```
cd src
npm run dev
```
