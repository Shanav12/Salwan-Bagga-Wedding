# Salwan-Bagga-Wedding

Main website for Sahil & Ambika's wedding.

## Steps to run
You must have node verion 20+. To do so with version 22 which I used, do the following:

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
source ~/.bashrc
nvm install 22
nvm use 22
```

To run the project:
```
cd src
npm run dev
```
